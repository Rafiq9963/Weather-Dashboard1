# 🌦️ Weather Dashboard

A cross-platform React Native weather application built with Expo and the OpenWeatherMap API.

---

## ✨ Features

* **Real-time Weather Data:** Fetches current temperature, weather conditions, humidity, and weather icons.
* **5-Day Forecast:** Displays daily weather trends and upcoming temperature outlooks.
* **GPS Auto-Detect:** Automatically prompts for location permissions and loads local weather for your exact coordinates.
* **Dark / Light Mode:** Switch themes dynamically with high-contrast UI adaptations.
* **Unit Conversion:** Easily toggle temperatures between Celsius (°C) and Fahrenheit (°F).
* **Saved Favourites:** Save, view, and remove preferred cities with persistent `AsyncStorage`.
* **Pull-to-Refresh:** Swipe down to instantly fetch refreshed weather metrics.
